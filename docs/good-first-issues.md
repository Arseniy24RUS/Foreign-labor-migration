# Good First Issues / Простые задачи для старта

These tasks are useful for new contributors because they are bounded, reviewable, and improve research readiness.

## Documentation

- Add a short glossary entry for one model output column.
- Check that README commands match the current CLI options and open an issue if they diverge.
- Add one FAQ item explaining the difference between stock need and annual quota.
- Translate one concise documentation note from English to Russian or Russian to English.

## Data QA

- Add a check that every local image referenced in README exists.
- Add a check that every local Markdown link in README exists.
- Verify that `docs/data/metadata.json` contains source labels for a refreshed run.
- Document one raw data file with source, access date, unit, and preprocessing note.

## Dashboard

- Improve one table label or tooltip without changing metric definitions.
- Add a small accessibility check for language toggle state.
- Confirm that the dashboard still renders after a dependency update.

## Русский

Хорошая первая задача должна быть небольшой и проверяемой: уточнить термин, добавить QA-проверку, описать источник или улучшить подпись в дашборде без изменения методологии.
