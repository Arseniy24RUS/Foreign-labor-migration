# Roadmap / Дорожная карта

This roadmap describes research-readiness priorities. It is not a promise of delivery dates.

## Near Term

- Keep `docs/methodology.md` synchronized with model formulas and dashboard metric names.
- Add small regression tests for README links, local image paths, and methodology references.
- Improve source metadata for raw EMISS/Rosstat files and population scenario inputs.
- Expand dashboard QA around stock versus annual quota metrics.

## Medium Term

- Add richer sensitivity reporting for `withMIG`, working-age definitions, unemployment mobilization, and migrant retention.
- Add a machine-readable model card or assumptions manifest.
- Improve geodata provenance and crosswalk diagnostics.
- Add examples for reproducing a full run from a clean clone.

## Research Extensions

- Add occupation and qualification layers when credible data are available.
- Compare alternative regional growth assumptions instead of a single common growth target.
- Add wage, vacancy, or sector-specific labor market constraints.
- Add uncertainty bands for productivity and demographic inputs.

## Русский

Ближайшие приоритеты: синхронизация методологии с формулами модели, улучшение метаданных источников, тесты ссылок и изображений, а также более явное разделение stock-дефицита и годовой квоты. Исследовательские расширения требуют отдельных обсуждений, особенно если они меняют смысл итоговых показателей.
